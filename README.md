## Simulazione di noto e-commerce
In questa esercitazione ho utilizzato selettori avanzati e il pseudo-classe `:hover` per aggiungere interattività. Ho impiegato le classi `position: relative` e `position: absolute` per posizionare correttamente l'icona dei preferiti, integrando anche icone con **Font Awesome** per arricchire l'interfaccia.
